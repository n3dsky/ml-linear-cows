# ml-linear-cows
# Прогнозная система для отбора молочных коров

**Проект машинного обучения для молочного хозяйства «Вольный луг»**

## Описание проекта

Молочное хозяйство **«Вольный луг»** планирует расширить поголовье коров через контракт с ассоциацией пастбищ **«ЭкоФерма»**. Чтобы минимизировать риски и обеспечить выполнение бизнес-плана, необходимо отбирать только тех коров, которые соответствуют строгим производственным стандартам.

### Ключевые критерии отбора коровы:
- Годовой удой ≥ 6000 кг
- Молоко должно классифицироваться как **«вкусное»** по внутренней методике фермера

Текущий процесс отбора слишком субъективен и зависит от заявлений продавцов. Проект решает эту проблему с помощью машинного обучения.

## Цели проекта

Разработать две прогнозные модели для объективной оценки коров при покупке:

1. **Модель 1: Прогнозирование удоя** (Регрессия)  
   Целевая переменная: `Удой` (кг/год)

2. **Модель 2: Оценка качества молока** (Классификация)  
   Целевая переменная: `Вкус молока`  
   Задача: предсказание вероятности категории «вкусное»

**Правило рекомендации к покупке:**
Корова рекомендуется, если:
- Спрогнозированный удой ≥ 6000 кг
- Вероятность «вкусного» молока ≥ 0.5

## Выполненные работы

- Проведена предобработка данных и исследовательский анализ
- Отобраны наиболее значимые признаки с логичной связью с целевыми переменными
- Добавлен новый признак из дополнительного источника данных
- Обеспечена линейная зависимость между признаками и целевой переменной для модели регрессии
- Обучены модели **линейной регрессии** и **логистической регрессии**
- Проанализированы метрики качества моделей с акцентом на риски и экономические последствия

## Выводы по моделям

- Модель линейной регрессии улучшена за счёт отбора признаков и создания нового признака.
- Для дальнейшего повышения качества моделей рекомендуется:
  - Добавить больше новых признаков в исходные данные
  - Увеличить объём обучающих данных

**Важные метрики при анализе рисков и экономических расчётов:**
- **Precision** — высокая точность предсказаний (критично, когда ложные срабатывания дороги)
- **Recall** — полнота обнаружения (критично, когда пропуск реального случая приводит к большим потерям)
